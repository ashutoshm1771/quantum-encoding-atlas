# Jupyter Notebooks

Tutorial notebooks for the Quantum Encoding Atlas.

## Tutorials

1. `tutorial_01_introduction.ipynb` - Introduction to quantum data encoding
2. `tutorial_02_encoding_deep_dive.ipynb` - Deep dive into encoding methods
3. `tutorial_03_analysis_tools.ipynb` - Using analysis tools
4. `tutorial_04_benchmarking.ipynb` - Running benchmarks
5. `paper_figures.ipynb` - Reproduce figures from the paper

## Running the Notebooks

```bash
pip install encoding-atlas[all]
jupyter notebook
```
